# Student State → Screen Matrix

This matrix establishes how the single backend truth is interpreted visually across different screens in the Student Web Application. 

*No screen may invent a state that contradicts this matrix.*

## 1. Registration States

| Backend State | Event Detail | My Events | Home (Summaries) | Notification |
|---|---|---|---|---|
| **REGISTERED** | `✓ Registered` | `Upcoming` / `Next` | `Upcoming commitment` | Only if generated by system |
| **WAITLISTED** | `◐ Waitlisted` | `Waiting` | `Contextual if relevant` | `You're on the waitlist` (Initial) / `Promotion` (Async) |
| **CANCELLED** | `Not registered` | Hidden/Archived | Hidden | - |
| *(None)* | `Register` | Hidden | Hidden | - |

## 2. Team Registration States

| Backend State | Team Flow (Event Detail) | My Events | Home | Notification |
|---|---|---|---|---|
| **FORMING** | `Forming` (Invite members) | `Forming` | `Action required` (if leader) | - |
| **REGISTERED** | `Registered` | `Upcoming` | `Upcoming team event` | `Team Registered` |
| **WAITLISTED** | `Waitlisted` | `Waiting` | - | `Team waitlisted` |

## 3. Team Invitation States

| Backend State | Team Invitation | Home | Notifications |
|---|---|---|---|
| **PENDING** | `Accept / Decline` | `Pending Invitation` | `Action required` |
| **ACCEPTED** | `View Team` | Hidden | - |
| **DECLINED** | `Declined` | Hidden | - |
| **EXPIRED** | `Expired` | Hidden | - |

## 4. Attendance States

| Backend State | Event Detail | Attendance History | My Events | Notification |
|---|---|---|---|---|
| **PRESENT** | `Attendance recorded` | `Present` | `Attended` | - |
| **ABSENT** | `No attendance record` | `No record` | `Past` | - |
| **EXCUSED** | `Attendance recorded` | `Excused` | `Attended` | `Dispute Approved` |

## 5. Dispute States

| Backend State | Attendance History | Event Detail | Notifications |
|---|---|---|---|
| **PENDING** | `Pending / Under review` | `Attendance issue pending` | - |
| **APPROVED** | `Approved (Excused)` | `Attendance recorded` | `Dispute Approved` |
| **REJECTED** | `Rejected` | `No attendance record` | `Dispute Rejected` |

## 6. Club States

| Backend State | Club Detail | My Clubs | Campus → Clubs |
|---|---|---|---|
| **MEMBER** | `Member` | Displayed | Displayed as member |
| *(Not a member)* | *(No member badge)* | Hidden | Displayed (discoverable) |
